# DX Companion 3.0.0

## English

Use **Settings → Companion** in DX Manager to install or update the official
app and grant cleanup permission. Android 13 or later is required.

- **File transfer** shows whether the PC is ready. Share files from Gallery or
  My Files with **Send to DX Manager**. For folders use the app's folder picker.
- **Cleanup** can close the display and release Stay awake. The simulated
  display cleanup timer is set in the app and defaults to immediate cleanup
  for new settings. Native DeX has its own reconnect grace of about 30 seconds.
- **App switch detection** is optional. Enable it in Settings and the Android
  Accessibility settings to use AI app automatic line breaks.

## 한국어

**설정 → Companion**에서 정식 앱을 설치하거나 업데이트한 뒤 정리 권한을 부여합니다.
Android 13 이상이 필요합니다.

- **전송**에서 PC가 파일을 받을 준비가 되었는지 확인합니다. 갤러리나 내 파일의
  공유 메뉴에서 **DX Manager로 보내기**를 선택합니다. 폴더는 앱에서 선택합니다.
- **휴대폰 정리**에서 가상 화면과 잠자기 방지를 정리합니다. 보조 방식의 자동 정리
  시간은 앱에서 설정하며, 새 설정에서는 즉시 정리합니다. 네이티브 DeX는 약 30초의
  재연결 유예를 사용합니다.
- **앱 전환 감지**는 AI 앱 자동 줄바꿈을 사용할 때 앱 설정과 Android 접근성에서 켭니다.
