# DX Manager v3.0.0

[Windows x64 ZIP](https://github.com/maze-mei/DX-Manager/releases/download/v3.0.0/DX-Manager-win-x64.zip)

## English

- Native DeX is the default activation mode for new settings. It waits about
  30 seconds for the same phone to reconnect after a connection drops.
- Simulated display remains available and is used for confirmed 120 FPS DeX
  launches. The saved DeX mode is used again for 30 or 60 FPS.
- Native DeX can restore the Bluetooth output that was in use before launch.
- Manual Enter / Shift+Enter switching is on for new settings. Use Scroll Lock
  to switch while a scrcpy window is active. AI app automatic line breaks are
  optional, off by default, with switches for ChatGPT, Claude, Gemini and Grok.
- Settings group related controls together. The English and Korean guides and
  FAQ explain the current settings, transfer paths and Companion setup.
- Includes scrcpy 5.0.1 and official shared DX Companion 3.0.0 (code 16).
- The Native DeX helper includes modified ScrcpyDeX v1.1 code under Apache 2.0.
  See the third-party notices under Settings → About.

**Windows package**  
Extract the complete DX Manager v3.0.0 folder from DX-Manager-win-x64.zip.
Keep the files together. Read and confirm the first-run notice when starting
from a fresh folder.

## 한국어

- 새 설정의 기본 실행 방식은 네이티브 DeX입니다. 연결이 끊기면 약 30초 동안
  같은 휴대폰의 재연결을 기다립니다.
- 보조 디스플레이 방식도 사용할 수 있습니다. 120 FPS DeX에 동의하면 이번 실행에
  보조 방식을 사용하며, 30 또는 60 FPS로 시작할 때는 저장한 방식을 따릅니다.
- 네이티브 DeX 시작 전 사용하던 Bluetooth 오디오 장치로 출력을 돌릴 수 있습니다.
- 새 설정에서 수동 Enter / Shift+Enter 전환이 켜집니다. scrcpy 창에서 Scroll Lock으로
  전환합니다. AI 앱 자동 줄바꿈은 기본 꺼짐이며 ChatGPT, Claude, Gemini, Grok을
  각각 켜거나 끌 수 있습니다.
- 관련 설정을 한 묶음에 배치했습니다. 한글·영문 사용설명서와 FAQ에 현재 설정,
  전송 경로와 Companion 앱 설정 방법을 반영했습니다.
- scrcpy 5.0.1과 공용 정식 DX Companion 3.0.0(code 16)을 포함합니다.
- 네이티브 DeX 보조 프로그램에 Apache 2.0으로 배포된 ScrcpyDeX v1.1 코드 일부를
  수정해 사용합니다. 설정 → 정보 → 제3자 라이선스 보기에서 확인할 수 있습니다.
