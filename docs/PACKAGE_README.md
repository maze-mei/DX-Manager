## English

1. Extract the whole folder to a writable location and open DXManager.exe.
2. Read the first-run notice, tick the acknowledgement box and select Confirm and start.
3. Enable USB debugging on the phone, connect it, and accept its prompt.
4. Select the phone and start DeX. Choose an app before starting Window 1–3.

Windows x64 7 SP1, 8.1, 10 or 11 with .NET Framework 4.6.2 or later.
The app's Help / Troubleshooting includes the full user guide and FAQ.
Use Settings → Companion to install or update the optional phone app.
Use Settings → About to check for updates or view third-party licenses.

Native DeX activation includes modified ScrcpyDeX v1.1 code under Apache 2.0.
The license and modification notice are in licenses.

## 한국어

1. 폴더 전체를 쓰기 가능한 위치에 풀고 DXManager.exe를 실행합니다.
2. 첫 실행 안내를 읽고 확인란을 선택한 뒤 **확인하고 시작**을 누릅니다.
3. 휴대폰의 USB 디버깅을 켜고 연결한 뒤 허용 창을 승인합니다.
4. 대상 휴대폰을 선택하고 DeX를 시작합니다. 단일창 1~3을 열 때는 앱을 선택합니다.

64비트 Windows 7 SP1, 8.1, 10 또는 11과 .NET Framework 4.6.2 이상이 필요합니다.
앱의 **도움말 · 문제 해결**에서 전체 사용설명서와 FAQ를 볼 수 있습니다.
**설정 → Companion**에서 선택형 휴대폰 앱을 설치하거나 업데이트합니다.
**설정 → 정보**에서 업데이트 확인과 제3자 라이선스 보기를 사용할 수 있습니다.

네이티브 DeX 화면 생성에는 Apache 2.0 라이선스의 ScrcpyDeX v1.1 수정 코드가 들어 있습니다.
원본 라이선스와 수정 고지는 licenses 폴더에 있습니다.
