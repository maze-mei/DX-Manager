DX Manager 한국어 사용 설명서

Windows v3.0.0
공용 DX Companion 3.0.0(code 16)과 scrcpy 5.0.1 기준입니다. 일부 화면 예시는 이전 UI입니다.

1. 준비 사항

PC

- 64비트 Windows 7 SP1, 8.1, 10 또는 11(32비트 Windows는 지원하지 않음)
- .NET Framework 4.6.2 이상
- Windows 7/8.1: 번들 레거시 ADB에 필요한 Universal CRT 업데이트
- 압축을 해제할 수 있는 충분한 저장 공간
- 실행 파일 옆에 설정·로그·스크린샷을 저장할 수 있는 쓰기 가능한 폴더

DX Manager는 Windows 7 SP1 및 오프라인·폐쇄망 PC를 지원하기 위한 최소
런타임으로 의도적으로 .NET Framework 4.6.2를 사용합니다. Windows 7 SP1에는
4.6.2가 기본 포함되지 않습니다. 설치되어 있지 않다면 Microsoft 공식 .NET
Framework 4.6.2 페이지에서
런타임을 받으십시오. 인터넷이 연결되지 않은 PC는 다른 컴퓨터에서 오프라인
설치 파일을 받은 뒤 옮겨서 설치할 수 있습니다. 4.7.2 또는 4.8이 이미 설치된
경우에는 4.6.2로 낮추거나 따로 설치할 필요가 없으며, 더 최신인 .NET
Framework 4.x가 이 요구 사항을 충족합니다.

휴대폰

- Samsung DeX를 지원하는 Samsung Galaxy 기기
- 개발자 옵션 활성화
- USB 디버깅 활성화
- 데이터 통신이 가능한 USB 케이블

기존 보조 방식은 Android 16 / One UI 8.x 등에서 사용한 경로입니다. 현재 네이티브 DeX 테스트는 Galaxy S26 Ultra / Android 17 / One UI 9.0에서 진행 중입니다. 모든 Galaxy·펌웨어의 동작을 보장하지 않으며, 지원이 불안정한 경우 다른 DeX 방식이나 단일창으로 비교하세요.

처음 연결할 때 휴대폰에 표시되는 RSA 디버깅 허용 창을 승인해야 합니다.
자주 사용하는 PC라면 이 컴퓨터에서 항상 허용을 선택할 수 있습니다.


2. 설치와 첫 실행

1. 배포 ZIP의 압축을 현재 계정이 쓸 수 있는 폴더에 풉니다. 별도 쓰기
   권한을 설정하지 않았다면 Program Files 같은 보호 폴더는 피하십시오.
2. DXManager.exe를 실행합니다.
3. Windows 보안 경고가 표시되면 파일의 출처를 확인한 뒤 실행 여부를
   결정합니다.
4. 휴대폰을 USB로 연결하고 RSA 디버깅을 승인합니다.
5. 상단 상태가 휴대폰 연결 상태로 바뀔 때까지 기다립니다.
6. DeX 시작을 누릅니다.


승인된 USB 또는 무선 기기를 감지하면 DX Manager는 설정된 기기 시작
대기시간이 지난 뒤 세션 시작 명령을 보냅니다. 기본값은 1초이며, 연결 직후
기기 상태가 안정된 다음 scrcpy를 시작하도록 돕습니다.

DXManager.exe만 다른 폴더로 복사하면 실행되지 않습니다. tools 폴더,
scrcpy DLL, scrcpy-server, 라이선스 파일을 포함한 배포 폴더 전체를
유지하십시오. 현재 개인 AI 키맵 테스트 번들은 scrcpy 5.0.1을 포함합니다.

[!IMPORTANT]
휴대폰을 연결한 상태에서 DeX 중지를 누르거나 Left Alt+F8을 누르거나,
시스템 트레이의 DX Manager 아이콘을 마우스 오른쪽 버튼으로 눌러 종료를
선택하십시오. 정리가 끝난 뒤 USB 또는 무선 연결을 끊으십시오.

남은 화면은 개발자 옵션 > 보조 디스플레이 시뮬레이션에서 아무 해상도나
한 번 선택하고, 같은 메뉴를 다시 열어 없음을 선택하면 제거됩니다.
처음부터 없음만 선택하면 남은 화면이 지워지지 않을 수 있습니다. 화면을
포함한 설명은 FAQ Q1을
참조하십시오.

여러 휴대폰 사용

DX Manager 2.0은 여러 물리 Galaxy 휴대폰을 동시에 관리할 수 있습니다. 현재
실행에서 확인된 휴대폰이 한 대뿐이면 기기 선택 영역을 숨기고, 두 번째
휴대폰이 감지되면 왼쪽에 표시합니다. 실행 중 한 대가 분리되어도 어떤 세션이
끊겼는지 확인할 수 있도록 이번 실행 동안 기기 항목을 유지합니다.

설정을 바꾸거나 세션을 시작하기 전에 왼쪽 기기 목록에서 대상 휴대폰을
선택하십시오. 휴대폰마다 DeX와 단일창 3개의 설정, 앱 프로필, USB·Wi-Fi
사용 정책, DX Companion 앱 세션과 양방향 파일 전송 상태를 따로 보존합니다.
같은 물리 휴대폰의 USB와 무선 ADB 연결은 하나의 기기 항목으로 합쳐집니다.
DX Manager는 그 휴대폰에서 사용자가 선택한 연결 방식만 사용하며 반대
transport로 임의 전환하지 않습니다.

scrcpy 창 제목에는 휴대폰 표시 이름이 포함됩니다. DX Companion 앱에서 PC로
받은 파일은 설정된 PC 저장 폴더 아래 휴대폰 이름별 하위 폴더에 나누어
저장됩니다.


3. DeX 모드

네이티브와 보조 방식 선택

설정 → 연결 → 네이티브 DeX에서 네이티브 DeX 또는 보조 디스플레이 시뮬레이션을 선택합니다. 새 설정의 기본값은 네이티브입니다. 명시적으로 저장한 사용자의 방식은 보존하며, 변경 후에는 DeX를 종료하고 다시 시작합니다.

네이티브는 휴대폰의 삼성 DeX 환경을 사용합니다. 보조 방식은 기존 경로로, 폰에 작은 보조 화면이 나타날 수 있지만 생성이 빠르고 실험적120프레임을 사용할 수 있습니다. 기기·앱에 따라 두 방식의 UI와 동작이 다를 수 있습니다.

120프레임과 화면 켜짐

네이티브 DeX는 최대 60 FPS로 동작합니다. DeX에서 120 FPS를 선택하고 전환에 동의하면 이번 실행에만 보조 방식을 사용합니다. 30 또는 60 FPS로 시작하면 저장한 DeX 실행 방식을 따릅니다.

방식 전환 안내를 건너뛰려면 설정 → 연결 → 네이티브 DeX를 펼쳐 120 FPS 실행 시 보조 방식으로 자동 전환을 켭니다. 안내창에서 ‘다음부터 이 안내 없이 보조 방식으로 실행’을 선택하는 것과 같은 설정입니다. 120 FPS 사용 경고는 매번 표시됩니다.

120 FPS를 선택하면 폰 화면 끄기가 해제되고 선택할 수 없게 됩니다. 30 또는 60 FPS로 돌아가면 이전 선택을 복원합니다. 실제 FPS는 기기와 앱, 입력 상태에 따라 달라집니다.

같은 휴대폰에서 네이티브 DeX가 실행 중이거나 화면이 재연결을 기다리는 동안 단일창은 60 FPS로 제한됩니다. 단일창에 설정한 120 FPS 값은 유지되며, 네이티브 화면이 정리된 뒤에는 설정한 최대 FPS까지 사용할 수 있습니다.

실제 FPS는 설정 → 진단 → 로그 창 열기에서 확인합니다. scrcpy 창을 선택하고 왼쪽 Alt+I를 누르면 FPS가 로그에 표시됩니다. 같은 키를 다시 누르면 표시를 끕니다.

연결 단절 후30초 유예

네이티브 DeX는 USB·Wi-Fi 단절 감지 후 약 30초를 기다린 뒤 해당 화면을 정리합니다.30초 안에 같은 폰이 다시 연결되면 정리를 취소하고 남은 화면을 재사용합니다. 시스템이 먼저 화면을 없앴다면 새로 생성합니다. PC 창을 자동으로 여는지는 기존 자동 실행 옵션을 따릅니다.

Companion 앱의 자동 정리 시간은 보조 방식에 적용됩니다. 네이티브 DeX는 연결이 끊기면 소리를 휴대폰으로 돌리고 잠자기 방지를 해제합니다. PC에서 DeX 창을 다시 열면 해당 세션의 소리와 전원 설정을 다시 적용합니다. Bluetooth 오디오로 듣고 있다면 그 출력을 유지합니다.

DeX를 열기 전에 듣던 Bluetooth 장치로 소리를 돌리려면 설정 → 연결 → 네이티브 DeX를 펼치고 네이티브 DeX 연결 시 Bluetooth 사운드 유지를 켭니다.

명시적인 DeX 중지·프로그램 종료·Windows 종료는30초를 기다리지 않고 정리합니다. 시스템 종료나 잠금 정책 때문에 화면이 유예보다 일찍 사라질 수 있어30초 생존 자체를 보장하지 않습니다. 보조 방식에는 기존 Companion 앱 자동 정리 설정을 사용합니다.


왼쪽 메뉴에서 DeX를 선택합니다. 시작 앱이 선택 안 함이어도 데스크톱을 열 수 있습니다. 시작 앱을 고르면 DeX를 열 때 그 앱도 실행됩니다.


화면 설정

- 해상도: 프리셋 또는 사용자 지정 크기
- DPI: Android 화면 배율
- 비트레이트: 영상 품질과 네트워크 사용량
- 최대 FPS: 30·60 또는 실험적120프레임

DPI 값이 작을수록 화면의 UI 요소가 작아져 한 화면에 더 많은 정보를 표시할
수 있습니다.

사용자 지정 해상도는 프리셋과 별도로 저장됩니다. 다른 프리셋을 선택한 뒤
다시 사용자 지정을 선택해도 마지막 사용자 지정 값이 복원됩니다.

scrcpy 창은 PC 모니터와 창 크기에 맞춰 영상을 자동으로 축소하여 표시합니다.
따라서 PC에서 보이는 창의 크기와 관계없이 실제 DeX 내부 해상도는 DX
Manager에서 설정한 값으로 동작합니다. 사용자 지정 가로·세로 값은 각각
4096까지 입력할 수 있습니다.

실행 옵션

- 폰 화면 끄기 (-S): scrcpy 실행 중 실제 휴대폰 화면 끄기
- HID 키보드 (-K): 키보드를 Android 입력 장치로 전달
- HID 마우스 (-M): 마우스를 Android 입력 장치로 전달
- 선택 앱 강제 종료: 앱을 시작하기 전에 기존 프로세스 종료
- 잠자기 방지 (-w): 실행 중 휴대폰 활성 상태 유지

폰 화면 끄기(-S)는 휴대폰을 잠그는 기능이 아니라 활성 상태에서 물리
디스플레이만 끄는 기능입니다. 화면이 꺼져 있어도 터치, 길게 누르기, 지문
인증 등의 입력은 동작할 수 있으므로 의도하지 않은 설정 변경이나 앱 조작에
주의하십시오.

HID 키보드와 HID 마우스를 끄면 scrcpy의 비 HID 입력 방식을 사용합니다.
이때 마우스 입력은 화면을 직접 터치하는 것처럼 전달되며, 마우스 버튼을
누르고 있으면 길게 누르기 동작으로 처리됩니다.

비 HID 키보드는 HID 방식과 일부 동작이 다릅니다. 영문 입력은 가능하지만
한영키가 동작하지 않을 수 있으므로 왼쪽 Shift+Space로 입력 언어를
전환하십시오. Android 키보드와 시스템 설정에 따라 이 조합도 동작하지 않을
수 있습니다.

설정을 변경한 뒤 실행 버튼을 누르면 필요한 경우 기존 DeX 세션을 정리하고
새 설정으로 다시 시작합니다.

PC로 소리를 전달하지 않으려면 메인 화면의 고급 옵션에서 scrcpy 추가 인자에 --no-audio를 넣고 세션을 다시 시작합니다.

4. 단일창 모드

왼쪽 메뉴에서 단일창 1, 단일창 2, 단일창 3 중 하나를
선택합니다. 각 슬롯은 해상도, DPI, 비트레이트, FPS, 앱과 실행 옵션을
독립적으로 기억합니다.

1. 앱 목록 불러오기를 누릅니다.
2. 시작할 앱을 선택합니다.
3. 화면과 실행 옵션을 설정합니다.
4. 단일창 시작을 누릅니다.

단일창은 실행할 앱을 선택해야 시작할 수 있습니다. 앱 목록이 선택 안 함이면 시작할 앱을 먼저 선택하세요.

앱 목록은 휴대폰마다 따로 보관하며 현재 DX Manager 실행 중 기기를 바꾸면
그 휴대폰에서 마지막으로 불러온 목록을 복원합니다. 완료하면 불러온 앱 개수를
잠깐 표시합니다. 기기 전환 뒤 늦게 도착한 결과는 원래 조회한 휴대폰에 저장합니다.

자동으로 정상 실행된 앱은 해당 휴대폰의 최근 앱 목록에 저장되어 같은 휴대폰의
다른 슬롯이나 다음 실행에서 선택할 수 있습니다. 예전 공통 최근 앱 데이터는
설정에 보존하되 특정 휴대폰에 자동 배정하지 않으며 저장된 시작 앱 선택은 유지합니다.

앱 프로필

단일창 모드는 선택한 Android 패키지마다 프로필 하나를 저장할 수 있습니다.
원하는 화면과 실행 옵션을 정한 뒤 프로필 저장을 누릅니다.
해상도, DPI, 비트레이트, FPS, 화면 끄기, 잠자기 방지, HID 입력, 강제 종료,
동적 창 크기와 추가 인자가 저장됩니다. 세 단일창 중 어느 슬롯에서든 같은 앱을
선택하면 저장된 프로필이 해당 슬롯에 자동으로 적용됩니다.

기존 프로필을 바꾸려면 옵션을 수정하고 프로필 저장을 다시 누릅니다. 프로필을
삭제해도 현재 슬롯에 이미 불러온 설정은 바뀌지 않으며, 단일창 프로필은 DeX
모드 설정에 영향을 주지 않습니다.

단일창은 DeX 가상화면을 재사용하지 않습니다. scrcpy의 새 가상 디스플레이
기능으로 각각 별도의 화면을 만들며, DeX와 단일창 3개를 동시에 실행할 수
있습니다.


- 동적 창 크기 (-x): 창 크기에 맞춰 가상 디스플레이 크기 조정
- 단일창 제목: DX Manager - 앱 이름
- DeX 창 제목: DX Manager - DeX Station

게임에 따라 HID 키보드와 HID 마우스를 끄고 단일창 모드를 사용하는 편이
입력 호환성이 더 좋을 수 있습니다.

5. 드래그 앤 드롭 파일 전송

실행 중인 DeX 또는 단일창의 scrcpy 창에 파일을 하나 이상 놓거나 폴더 전체를
놓을 수 있습니다. DX Manager 파일 전송은 기본값으로 켜져 있으며, Windows
7 SP1부터 11까지 호환되는 경로로 한글·일본어 등 Unicode 이름을 보존합니다. 휴대폰의 기본
저장 위치는 /sdcard/Download/입니다. 설정 → 경로 → 파일 전송 경로에서
PC → 휴대폰 파일 전송을 펼쳐 휴대폰 대상 폴더를 바꿀 수 있습니다.
휴대폰에서 선택을 누르면 연결된 휴대폰의 폴더를 고를 수 있습니다.
/sdcard/ 또는 /storage/emulated/0/ 아래의 폴더를 지정합니다.
변경한 위치는 새로 여는 DeX와 단일창부터 적용됩니다.

폴더를 놓으면 최상위 폴더, 하위 폴더, 파일과 빈 폴더를 그대로 보존합니다.
선택한 폴더 밖으로 따라가지 않도록 정션, 심볼릭 링크 등 재분석 지점은
건너뜁니다. APK 파일을 단독으로 놓으면 scrcpy의 설치 동작을 유지하고, 폴더
안에 포함된 APK는 일반 파일로 복사합니다.

독립적으로 이동할 수 있는 작은 상태창은 처음에 scrcpy 창 옆에 열립니다.
현재 전송 항목과 다음 대기 항목 4개, 파일 크기, 경과 시간 및
완료·실패·대기 수를 표시합니다. 지원하는 모든 Windows와 ADB 조합에서 정확한
전송 바이트를 얻을 수 없으므로 진행률과 남은 시간은 표시하지 않습니다.
취소를 누르면 해당 scrcpy 창의 진행 중·대기 중 전송을 모두 중단하고
휴대폰의 임시 데이터를 정리하도록 시도합니다. 이미 끝난 이동 결과가 엇갈리지
않도록 짧은 최종 저장 단계에서는 취소 버튼이 비활성화됩니다.

휴대폰의 기존 파일과 폴더는 덮어쓰지 않습니다. 같은 이름이 있으면
이름 (1).확장자, 이름 (2).확장자 또는 폴더 (1)로 저장합니다.

6. USB 연결

기본 연결 방식입니다.

1. 휴대폰에서 USB 디버깅을 켭니다.
   USB 디버깅 항목이 회색으로 표시되어 선택할 수 없다면 Galaxy의
   설정 > 보안 및 개인정보 보호 > 보안 위험 자동 차단을 확인하십시오.
   이 기능을 끄면 USB 디버깅을 활성화할 수 있습니다. 세부 설정의
   자동으로 켜기가 활성화되어 있으면 약 30분 후 자동 차단이 다시 켜져
   USB 디버깅 연결이 끊어질 수 있습니다. 메뉴 이름과 위치는 One UI 버전에
   따라 다를 수 있습니다.
2. USB 케이블로 PC와 휴대폰을 연결합니다.
3. RSA 디버깅 허용 창을 승인합니다.
4. DX Manager에서 연결 상태를 확인합니다.

장치가 나타나지 않으면 케이블, USB 포트, Samsung USB 드라이버와 RSA
승인 상태를 확인한 뒤 설정 > 진단 > 환경 점검 실행을 사용하십시오.

7. 무선 연결

USB로 무선 연결 준비

처음 연결하거나 휴대폰 재부팅 후 가장 간단한 방법입니다.

1. PC와 휴대폰을 같은 로컬 네트워크에 연결합니다.
2. 휴대폰을 승인된 USB 디버깅 상태로 연결합니다.
3. 설정 > 연결에서 무선 ADB 연결 사용을 선택합니다.
4. 휴대폰 IP 주소를 비워두면 프로그램이 Wi-Fi 주소를 자동으로 찾습니다.
5. 연결 포트를 확인합니다. 기본값은 5555입니다.
6. USB로 무선 준비를 누릅니다.
7. 무선 연결 성공을 확인한 뒤 USB 케이블을 분리합니다.

IP 자동 감지에 실패하면 휴대폰의 Wi-Fi 상세 화면에서 IPv4 주소를 확인해
직접 입력하십시오.

Android 11 이상 무선 페어링

1. 휴대폰의 개발자 옵션 > 무선 디버깅을 켭니다.
2. 페어링 코드로 기기 페어링을 엽니다.
3. DX Manager에 휴대폰 IP, 페어링 포트와 6자리 코드를 입력합니다.
4. 페어링을 누릅니다. DX Manager가 연결 endpoint를 자동 검색하고 대상
   휴대폰 하나로 확인되면 자동 연결합니다.
5. 자동 검색을 사용할 수 없거나 후보가 여러 개면 무선 디버깅 기본 화면의
   연결 포트를 입력하고 무선 연결을 눌러 수동으로 연결합니다.

페어링 포트와 연결 포트는 다르며, 무선 디버깅을 다시 켜면 연결 포트가 바뀔 수
있습니다. DX Manager는 해당 연결이 페어링한 휴대폰인지 검증한 뒤 저장 주소를
갱신합니다. 페어링 코드는 설정이나 로그에 저장되지 않습니다.

무선 연결 문제

- PC와 휴대폰이 같은 Wi-Fi 이름을 사용해도 서로 통신하지 못할 수 있습니다.
- 게스트 Wi-Fi, AP 격리, 클라이언트 격리, VLAN과 회사 방화벽을 확인합니다.
- endpoint 자동 검색이 차단되면 페어링 포트가 아닌 휴대폰 무선 디버깅 화면의
  현재 연결 포트를 수동 입력합니다.
- 휴대폰 재부팅 후에는 USB 무선 준비가 다시 필요할 수 있습니다.
- 5GHz에서 최초 연결이 실패하면 공유기 설정을 확인하거나 2.4GHz에서
  연결을 초기화한 뒤 다시 시도해 볼 수 있습니다.

8. 화면 캡처

캡처 단축키는 scrcpy 창이 활성화된 상태에서만 동작합니다.

1. F8을 누르면 scrcpy 창이 전면으로 오고 안내가 표시됩니다.
2. F8을 다시 누르면 scrcpy의 화면 영역만 캡처합니다.
3. 마우스로 드래그하면 선택한 영역을 캡처합니다.
4. Esc를 누르면 취소합니다.

드래그 캡처는 scrcpy 창 내부로 제한되지 않습니다. 웹페이지, 문서, 다른
프로그램 등 PC 화면의 필요한 영역을 선택해 캡처한 뒤 바로 휴대폰으로
전송하는 용도로도 사용할 수 있습니다.

캡처는 기본적으로 실행 폴더의 screenshot에 저장됩니다. 설정 → 경로의
PC 스크린샷 저장 폴더에서 위치를 바꿉니다. 캡처 후 폰으로 전송을 켜면
같은 페이지에서 지정한 휴대폰 스크린샷 저장 폴더에도 보냅니다.

DX Manager가 만든 가상 DeX 화면에서는 DeX 작업 표시줄의 스크린샷 버튼이
작동하지 않습니다. 화면을 저장하려면 DX Manager의 F8 캡처 기능을
사용하십시오.

9. 키 입력 보정

AI 앱별 Enter 자동 줄바꿈

설정 → 입력 → AI 앱 자동 줄바꿈을 켜면 앱 목록이 펼쳐집니다.
ChatGPT, Claude, Gemini, Grok의 스위치를 각각 켜거나 끌 수 있습니다.
켜둔 앱에서 Enter를 Shift+Enter로 바꾸고, 나머지 앱에서는 일반 Enter를 보냅니다.
Gemini 스위치는 Gemini 앱과 설치된 Gemini 웹앱에 함께 적용됩니다. AI 자동 줄바꿈의 기본값은 꺼짐입니다.

휴대폰에 DX Companion 3.0.0을 설치하고 Companion 앱 → 설정 → 앱 전환 감지 카드 → 접근성 설정 열기 → 설치된 앱 → DX Companion 앱 → 사용 중 순서로 켭니다. 접근성은 앱 감지용 선택 권한이며 파일 전송/기본 DeX의 필수 조건이 아닙니다. 앱 정보를 받지 못하면 기본 Enter를 사용합니다.

AI 자동 줄바꿈을 켜면 수동 Enter / Shift+Enter 전환이 꺼집니다.
Scroll Lock으로 수동 전환하려면 Enter / Shift+Enter 전환을 켭니다.
일반 Enter로 시작하며, scrcpy 창에서 Scroll Lock을 누를 때마다 일반 Enter와 Shift+Enter가 바뀝니다.
수동 전환은 새 설정에서 기본 켜짐이며 Companion 앱 없이 사용할 수 있습니다.


키 입력 보정은 scrcpy 창이 활성화된 경우에만 적용됩니다.

- 한영키 보정: 한영키를 Android의 Shift+Space로 전달
- 오른쪽 Windows 키 보정: Android 입력 호환성 보정
- 직접 입력한 Shift+Space를 무시하는 옵션 제공(기본값 꺼짐)

Windows용 scrcpy 4.0/SDL3에서는 Windows가 물리 오른쪽 Shift를 감지해도
Android로 전달되지 않는 현상을 재현했습니다. DX Manager는 SDL3 기반
scrcpy 4.x 클라이언트와의 호환을 위해 해당 scrcpy 창이 활성화된 동안에만
오른쪽 Shift를 왼쪽 Shift로 변환합니다. 일반적인 Shift 타이핑은 정상
동작하지만 해당 세션에서 Android는 좌우 Shift를 구분하지 못합니다.

기본 캡처 단축키는 F8, 종료 단축키는 왼쪽 Alt+F8입니다. 설정 → 입력에서
해당 입력란을 선택하고 사용할 키를 누릅니다. Ctrl, Alt, Shift 같은 보조키를
조합할 때는 F8 같은 일반 키도 함께 누르세요.

자주 사용하는 scrcpy 단축키

다음은 Samsung DeX 자체 단축키가 아니라 scrcpy 창 단축키입니다. 아래 예시는
scrcpy의 기본 단축키 보조 키 중 하나인 왼쪽 Alt를 사용합니다.

| 단축키 | 동작 |
| --- | --- |
| Alt+F 또는 F11 | 전체 화면 전환 |
| Alt+G | 현재 영상의 1:1 픽셀 크기에 맞춰 창 크기 조정 |
| Alt+I | 세션 로그의 FPS 표시 켜기·끄기 |
| Alt+P | 휴대폰 전원 버튼 누르기 |
| Alt+O | 휴대폰 화면 끄기 (O는 숫자 0이 아닌 영문자 O) |
| Alt+Shift+O | 휴대폰 화면 켜기 |
| Alt+V | PC 클립보드를 동기화하고 붙여넣기 |
| Ctrl+V | 활성 Android 앱에 Ctrl+V 전달(앱에 따라 동작) |

다른 scrcpy 5.0.1 공식 단축키도
사용할 수 있지만, 일부 Android 시스템 단축키는 가상 DeX 화면에서 동작하지
않거나 휴대폰의 기본 화면에서 실행될 수 있습니다.

미니 컨트롤바

설정 > 기본 > Scrcpy 창 옆에 미니 컨트롤바 표시를 켜면 각 DeX·단일창에
전용 미니바가 나타납니다. 연결된 scrcpy 창을 따라다니며 휴대폰 화면 끄기·켜기,
전원 버튼, 전체 화면, 1:1 창 크기, 캡처와 DX Manager 열기를 제공합니다.
버튼에 마우스를 올리면 기능 설명과 해당 단축키가 표시됩니다.

설정 > 기본에서 왼쪽 또는 오른쪽 위치를 고를 수 있고, 맨 아래 버튼으로
접거나 펼칠 수 있습니다. 연결된 창의 활성화, 최소화와 앞뒤 순서를 따라가므로
뒤에 있는 세션의 미니바가 활성 세션 위를 가리지 않도록 관리됩니다.

10. 자동 숨김과 시스템 트레이

자동 숨김을 사용하면 설정된 시간 동안 입력이 없을 때 scrcpy 창과 DX
Manager UI가 숨겨지고 프로그램은 시스템 트레이로 이동합니다.

입력이 발생했다고 자동으로 다시 나타나지는 않습니다. Windows 작업
표시줄의 scrcpy 창을 클릭하거나, 트레이 아이콘을 두 번 클릭하거나, 트레이
메뉴에서 열기를 선택해 창을 복원합니다.

프로그램 창의 닫기 버튼은 DX Manager를 트레이로 숨깁니다. 완전히 종료하려면
Left Alt+F8을 누르거나 트레이 아이콘을 마우스 오른쪽 버튼으로 눌러
종료를 선택하십시오. 세션 정리가 끝날 때까지 휴대폰 연결을 유지하십시오.

11. 로그와 환경 점검

로그

로그 보기는 현재 세션을 표시하며 수동 저장도 가능합니다. 설정 → 진단 → 세션 로그 열기 아래의 세션 로그 자동 저장을 켜면 프로그램 폴더의 logs에 세션·진단 파일을 기록합니다. 새 설정의 기본값은 꺼짐이며 기존 테스트의 켜진 선택은 보존합니다. 체크를 꺼도 메모리 로그와 기존 파일을 삭제하지 않습니다.

로그 보기에서 주요 진행 안내는 시간·레벨·본문 전체 보라, 경고/오류는 주황/빨강, 일반 도구 입출력과 scrcpy 원문은 기본색입니다. 파일에는 색상용 새 태그를 넣지 않습니다.

로그에는 다음 정보가 포함될 수 있습니다.

- 선택된 ADB와 버전
- 장치 연결 상태
- DeX 및 단일창 실행 결과
- display ID 탐색 결과
- scrcpy 출력과 오류

여러 platform-tools 버전은 공통 프로토콜 문구인 Android Debug Bridge
version 1.0.41을 출력합니다. DX Manager는 그 다음 Version ... 줄에서 실제
빌드 값을 읽어 표시합니다. 번들 scrcpy ADB는 37.0.1-15733141, 번들 레거시
ADB는 34.0.1-9979309로 표시됩니다.

업데이트 확인

DX Manager는 로컬 날짜 기준으로 하루 한 번 GitHub 업데이트를 백그라운드에서 확인합니다.
설정 → 정보 → 업데이트 확인에서 직접 확인할 수도 있습니다.
새 버전이 있으면 GitHub 릴리스 페이지에서 받을 수 있습니다.

환경 점검

설정 > 진단 > 환경 점검 실행에서 ADB, scrcpy, Windows, 장치 연결과
주요 폴더 상태를 확인할 수 있습니다.

선택 기기 버전 카드에는 현재 선택한 휴대폰의 모델, 연결 방식, Android
버전, SDK 수준, One UI와 보안 패치가 표시됩니다. 호환성 판정은 참고 정보이며
실행을 차단하지 않습니다. 펌웨어 업데이트나 연결 방식 변경 뒤에는 새로 고침을
누르십시오.

진단 보고서 저장은 기기 이름, serial, IP 주소, 토큰과 로컬 경로를 가린 텍스트
보고서를 만듭니다. 외부 ADB·scrcpy 메시지에는 환경별 정보가 남을 수 있으므로
공유하기 전에 내용을 한 번 확인하십시오.


진단 페이지에서 고급 옵션 표시를 누르면 기기 감시 주기, 가상
디스플레이 감지 제한시간, ADB Wake-up, 프로세스 제한시간과 캡처 선택
대기시간을 설정할 수 있습니다. 이러한 감시·복구용 값은 일반적으로 변경할
필요가 없습니다.

설정의 Companion 앱 페이지에서 번들 Companion 앱을 현재 선택된 휴대폰에
설치·업데이트·재설치하거나 권한을 부여하고 삭제할 수 있습니다. 어떤 동작도
자동으로 시작되지 않습니다. DX Manager는 설치 전 정확한 APK 해시와 번들 서명을
확인하고, 설치 후에도 패키지명·버전·서명과 권한 상태를 다시 검증합니다. 다른
앱에는 권한을 부여하지 않습니다.

휴대폰이 연결되지 않았거나 정리 앱이 없거나 서명이 일치하지 않으면 버튼은
비활성화되고 이유가 표시됩니다. 이미 권한이 있으면 권한 부여됨으로
표시됩니다. 이 권한은 정리 앱이 Android의 가상화면 설정을 삭제하기 위한
것이며 임의의 ADB 명령 실행 권한을 제공하지 않습니다.


앱 보안과 다중 디스플레이 제한

일부 금융·게임·스트리밍·보안 앱은 USB 디버깅이나 개발자 옵션이 켜진
환경에서 실행을 거부할 수 있습니다. 보안 화면 또는 DRM 콘텐츠가 검게
표시되거나 가상·보조 디스플레이 실행이 차단될 수도 있습니다. DX Manager는
이러한 앱과 Android의 보안 정책을 우회하지 않습니다.

다중 디스플레이를 완전히 지원하지 않는 앱은 DeX에서 실행해도 휴대폰 화면에
열릴 수 있습니다. 휴대폰에서 앱을 완전히 종료하거나 선택 앱 강제 종료를
사용한 뒤 다시 실행해 보십시오.

문제를 제보할 때는 비밀번호, 페어링 코드나 민감한 네트워크 정보가 없는지
확인한 뒤 저장한 로그를 첨부하십시오.

12. 선택형 DX Companion 앱

DX Companion은 Android 13 이상용 선택형 전송·정리 앱입니다. 현재 번들은 스토어판과 공용인 3.0.0(code 16)입니다. 기본 DeX·단일창은 미설치 상태에서도 사용할 수 있습니다.

설치와 최초 권한 부여

1. 대상 폰을 ADB로 승인하고 DX Manager의 설정 → Companion을 엽니다.
2. 설치/업데이트를 직접 선택합니다. APK와 대상 기기의 package·버전·서명을 검증한 뒤 필요한 보호 권한을 부여합니다.
3. APK를 별도로 설치했다면 권한 부여 버튼으로 상태를 확인합니다. 삭제 후 재설치하면 다시 부여해야 합니다.

번들 APK는 tools\companion\DX-Companion.apk입니다.
공유 메뉴에서 DX Companion 앱을 고를 때 현재 공용 APK에는
DX Manager로 보내기로 표시됩니다.

상태 카드와 수동 정리

홈에는 PC 연결 상태와 실제 확인된 네이티브 DeX 카드가 표시됩니다. 실행 중/PC 화면 연결 대기 상태를 구분하며, 저장된 복구 기록만으로 화면이 살아 있다고 단정하지 않습니다. 정리 탭에서 가상화면 또는 절전모드 해제를 개별/동시 정리할 수 있습니다. 타일과2×1 위젯도 지원하며 앱에서 정리 대상을 고릅니다.

네이티브 화면을 수동으로 정리하면 소유한 세션에 종료를 요청합니다. 보조 방식 정리는 전역 overlay_display_devices 설정을 제거하므로 사용자가 개발자 옵션에서 수동 생성한 보조 화면도 함께 제거될 수 있습니다. 다른 TV/수신기를 대상으로 범용 해제를 하지 않습니다.

연결 해제 후 자동 정리

보조 방식은 기존 선택값인 즉시·1분·5분·10분·30분·자동 정리 안 함을 사용합니다. 새 설정의 기본값은 즉시이며, 이미 저장한 유효한 선택은 보존합니다. 같은 세션이 재연결되면 예약을 취소합니다.

네이티브 DeX는 위 선택과 무관하게 단절 감지 후 약 30초 유예 뒤 정리합니다. 유예 중 사운드 전환·절전 해제는 바로 처리하고 Bluetooth 예외를 유지합니다. 명시적 중지·정상 종료·Windows 종료는 즉시 정리합니다. 시스템이 먼저 종료하면 화면을 계속 살려둘 수는 없습니다.

Windows 종료에서는 새 ADB 프로세스를 실행하지 않고 미리 연결된 보호 채널과 폰의 보조 프로세스로 가능한 정리를 시도합니다. 평소에는 DeX 중지나 트레이 종료를 사용하세요. 이전 테스트 helper 화면이 남아 있으면 새 버전 적용 전에 한 번 정리하고 다시 시작합니다.

선택형 앱 전환 감지와 접근성

AI Enter 자동 줄바꿈을 사용할 때만 접근성을 켭니다. 설정 순서는 Companion 앱 → 설정 → 앱 전환 감지 카드 → 접근성 설정 열기 → 설치된 앱 → DX Companion 앱 → 사용 중입니다. 기본 꺼짐이며 일반 전송에는 필요하지 않습니다. 활성 앱/화면 메타데이터를 사용하고 타이핑 내용을 저장하거나 보내지 않습니다. 이 앱에는 임의 shell 명령·클라우드 전송·분석 수집 기능을 추가하지 않았습니다.

휴대폰에서 PC로 파일과 폴더 보내기

1. DX Manager를 실행하고 전송할 휴대폰을 USB 또는 무선 ADB로 연결합니다.
2. DX Companion 앱의 전송 탭에서 DX Manager가 연결되어 파일을 받을
   준비가 되었습니다라는 안내를 확인합니다.
3. 갤러리나 내 파일에서 파일을 선택한 뒤 공유 메뉴의 DX Manager로 보내기
   (DX Companion)를 선택합니다.
4. 폴더는 DX Companion 앱의 전송 → 폴더 선택에서 보냅니다.


파일은 기본적으로 다운로드 → DX Manager → 휴대폰 이름 폴더에 저장됩니다.
설정 → 경로 → 파일 전송 경로의 휴대폰 → PC 파일 전송에서 PC 수신 폴더를
바꿀 수 있습니다. 파일은 연결된 휴대폰에서 PC로 바로 전송됩니다.
PC 대상 폴더에 같은 이름이 있으면 원본을 덮어쓰지 않고 이름 (1), 이름 (2)
형식으로 저장합니다.

DX Manager가 실행 중이 아니거나 대상 휴대폰이 연결되지 않았거나, 검증된 DX
Companion 앱이 설치되지 않은 경우에는 연결 대기 안내가 표시되고 전송이 시작되지
않습니다. 여러 파일을 공유할 수 있으며 폴더는 하위 구조와 빈 폴더를 유지합니다.

13. 언어, 테마와 설정 초기화


- 표시 언어: 자동, 한국어, 영어

- 테마는 저장 즉시 적용됩니다.

설정 > 진단 > 모든 설정 기본값 복원을 사용하십시오.

설정 파일은 실행 폴더의 config/settings.json에 저장됩니다.

15. 제거

DX Manager는 별도 설치 프로그램을 사용하지 않습니다.

1. DX Manager를 완전히 종료합니다.
2. 필요한 스크린샷과 로그를 백업합니다.
3. 압축을 풀었던 DX Manager 폴더를 삭제합니다.

Windows 자동 실행을 사용했다면 삭제 전에 설정에서 자동 실행을
해제하십시오.
